# Quickstart: Product Color Variants

## Validation Scenarios

1. Navigate to `http://localhost:5124/product/1`
2. Observe multiple color swatches (e.g. Black, Brown).
3. Click "Brown" - observe the main product image instantly changing to a brown wallet image.
4. Click "Black" - observe the main product image instantly changing back to the black wallet image.
5. Navigate to `http://localhost:5124/product/3` (a product without multiple colors).
6. Observe that it simply displays "Color: [ColorName]" instead of interactive swatches.
