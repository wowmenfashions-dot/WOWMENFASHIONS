# Quickstart: Admin Product Color Variants

## Validation Scenarios

1. Navigate to the Admin Dashboard `http://localhost:5124/admin/products`.
2. Edit an existing product (e.g., "Men's Classic Blazer").
3. Ensure the product has available colors defined (e.g., "Red,Black").
4. Under a new "Color Variants" section, upload or provide an image URL for "Red" and a different image URL for "Black".
5. Save the product.
6. Navigate to the frontend product details page for that product.
7. Click the "Red" color swatch and verify the main image changes to the Red variant image.
8. Click the "Black" color swatch and verify the main image changes to the Black variant image.
