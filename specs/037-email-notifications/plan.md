# Implementation Plan: Order Email Notifications

**Branch**: `037-email-notifications` | **Date**: 2026-09-27 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/037-email-notifications/spec.md`

---

## Summary

Add transactional email notifications to the WOWMENFASHIONS Blazor application using **Azure Communication Services (ACS) Email**. Two email types are required:
1. **Order Confirmation** — sent automatically to the customer when a Razorpay payment is confirmed and the order is saved.
2. **Order Status Update** — sent automatically to the customer when an admin updates the order's status from the admin dashboard.

Emails are dispatched as **Hangfire background jobs** (already used in the app) to ensure non-blocking, retriable delivery. All email attempts are logged to a new `EmailNotificationLogs` SQL table.

- `Azure.Communication.Email` (new NuGet package to install)

**Storage**: Azure SQL Database — new `EmailNotificationLogs` table (see [data-model.md](data-model.md))

**Testing**: Manual validation per [quickstart.md](quickstart.md)

**Target Platform**: Azure App Service on Linux (.NET 10)

**Project Type**: Blazor Server Web Application

**Performance Goals**: Emails delivered within 60 seconds of triggering event. Email sending must add 0ms to checkout or admin page response time (Hangfire background dispatch is near-instant).

**Constraints**: Email failures must never interrupt order flow. Connection strings stored in Azure App Service Application Settings, never in source code.

## Key Implementation Notes

### 1. NuGet Package
```bash
dotnet add package Azure.Communication.Email
```

### 2. `IEmailNotificationService` Interface
```csharp
public interface IEmailNotificationService
{
    Task SendOrderConfirmationAsync(int orderId);
    Task SendOrderStatusUpdateAsync(int orderId, string newStatus);
}
```

### 3. Hangfire Dispatch in CheckoutService
After `transaction.Commit()` in `CreatePendingOrderAsync`:
```csharp
BackgroundJob.Enqueue<IEmailNotificationService>(s => s.SendOrderConfirmationAsync(newOrderId));
```

### 4. Hangfire Dispatch in OrderService
After `UpdateOrderStatusAsync` executes:
```csharp
BackgroundJob.Enqueue<IEmailNotificationService>(s => s.SendOrderStatusUpdateAsync(orderId, status));
```

### 5. Email Template Strategy
HTML email strings are built inline in `EmailNotificationService` using C# string interpolation. Branded with WOWMENFASHIONS dark theme colours (#1a1a1a background, gold accent).

### 6. Azure App Service Settings (Production)
| Setting Name | Value |
|---|---|
| `AzureCommunicationServices__ConnectionString` | From ACS resource → Keys |
| `AzureCommunicationServices__SenderAddress` | Verified sender address |
